
# A7 Fintech

Criamos tecnologia para tornar a vida financeira mais simples e organizada.

## Koin

O Koin é uma plataforma de finanças pessoais que ajuda a acompanhar transações, planejar orçamentos e organizar objetivos financeiros em um só lugar.

Este espaço reúne os projetos e ferramentas que construímos para desenvolver o Koin.
